# The Universe Within — Миний дотоод ертөнц

React + Vite дээр хийсэн портфолио. Дэлхий дээр 4 өөр арал хөвж байна:
- **Knowledge Island**: намтар, ур чадвар (арлыг тойрон гарагууд эргэнэ)
- **Creativity Island**: сонирхол, өнгө цацдаг зурах талбар (интерактив)
- **Project Island**: бүтээлүүд (цонх нь анивчдаг тосгон)
- **Future Island**: мөрөөдөл болон холбоо барих «дохио»

Арал бүр өөрийн өнгө, SVG дүрс, хөдөлгөөнтэй. Хулганаар parallax эффект үүснэ. Бүгдийг өөрөө SVG, CSS, React state-ээр бичсэн.

## Ажиллуулах
`npm install` → `npm run dev` · Build: `npm run build` (Output: `dist`)

## Эх сурвалж
Бэлэн загвар, UI сан ашиглаагүй. (Ашигласан зүйл байвал энд заана.)

## Нууц (easter egg)
Future Island-ийн цонхны баруун доод буланд бүдэг «✦» од байна. 3 удаа дарвал солир бороо орно.

## Эффект
Арал дээр дарахад камер арал руу «нисч», арлуудыг холбосон гэрлийн зам дагуу гэрэл гүйнэ.
