# The Universe Within — Миний дотоод ертөнц

React + Vite дээр хийсэн галактик загвартай портфолио. Нүүр хэсэгт 4 арал хөвж байх бөгөөд арал бүр өөрийн цонхоор мэдээллээ харуулна. Нүүрний доор ердийн вэбсайтын хэсгүүд үргэлжилнэ.

## Арлууд
- "Миний ертөнц": нэр, боловсрол, сонирхол
- "Бүтээлийн ертөнц": бүтээлүүд. Төсөл сонгож, зураг сумаар солино. Зураг дээр дарж томруулна, тайлбар, технологи, холбоос байна
- "Ур чадварын ертөнц": ур чадвар бүлгээрээ
- "Харилцаа холбооны ертөнц": имэйл, GitHub, LinkedIn

Арал бүр өөрийн өнгө, SVG дүрс, хөдөлгөөнтэй. Хулганаар parallax эффект үүснэ. Бүгдийг өөрөө SVG, CSS, React state-ээр бичсэн.

## Ажиллуулах
`npm install` → `npm run dev` · Build: `npm run build` (Output: `dist`)

## Агуулга засах
Нэр, боловсрол, сонирхол, бүтээл, ур чадвар, холбоо барих мэдээлэл бүгд `src/data.js` дотор байна (`me`, `about`, `works`, `skills`). Бүтээл бүрд дээд тал нь 5 зураг (`imgs`) харагдана. Зураггүй бол өнгөт загвар гарна.

## Бүтэц
Дээд навигацтай, олон хэсэгтэй вэбсайт: нүүр (4 арал бүхий ертөнц) → Миний тухай → Бүтээлүүд → Ур чадвар → Холбоо барих → footer.

## Навигац
- "Дээд цэс": арал руу биш, нүүрний доорх харгалзах хэсэг рүү жигд гүйлгэнэ. Гүйлгэх үед идэвхтэй товч автоматаар солигдоно.
- "Зүүн дээд од": нүүр хэсэг рүү буцаана.
- "Арал дээр дарах": камер арал руу «нисч», мэдээллийн цонх нээгдэнэ. Нислэгийн үед арлуудыг холбосон гэрлийн зам дагуу гэрэл гүйнэ.
- "Footer": «Цэс» болон «Бүтээлүүд» товчнууд харгалзах арлын цонхыг нээнэ. Бүтээл дээр дарвал тэр төсөл сонгогдсон байна.
- "Хөтчийн «Back» товч": арлын хаяг (`#about`, `#works`, `#skills`, `#contact`) дагуу ажиллана.

## Гар
- `Esc`: цонх хаана
- `←` / `→`: нээлттэй цонхноос өмнөх, дараагийн арал руу шилжинэ
- Зураг томруулсан үед `←` / `→` зураг солино, `Esc` зөвхөн томруулалтыг хаана

## Нууц (easter egg)
Харилцаа холбооны ертөнцийн цонхны баруун доод буланд бүдэг «✦» од байна. 3 удаа дарвал солир бороо орно.

## Бусад
- Гар утсанд зохицно (арлууд 2 баганаар, цэс шахагдана)
- `prefers-reduced-motion` тохиргоотой хэрэглэгчид анимацгүй харна
